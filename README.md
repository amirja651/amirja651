## Hi, I'm Amir

Embedded firmware developer based in Canada. I write firmware for STM32 and ESP32 products and build the automated tests that prove it works on real hardware.

### What I work on
- Firmware in C and C++, bare metal or FreeRTOS: drivers, DMA, timers, low-power modes, fault recovery
- Motion control: TMC5160 stepper drivers, encoders, PID tuning, motion profiles
- Hardware-in-the-loop (HIL) test benches with Python and pytest, plus CI/CD
- Communication: CAN, RS-485, SPI, I2C, UART, Wi-Fi, BLE
- Board bring-up, schematics and PCB prototypes (OrCAD, Altium)

### Selected projects
- **Laser mirror alignment:** 1.5 µm positioning accuracy with STM32, FreeRTOS and closed-loop PID
- **Handheld GS1 DataMatrix scanner:** 300 ms scan-to-result, 8–10 hours of battery life
- **Fire alarm network:** STM32 sensor nodes and an ESP32 controller over CAN bus
- **HIL simulator** for end-of-line testing of elevator control panels
